## §3 Technical Design

### 3.1 Tech Stack

**后端**：Node ≥20.6 / TypeScript 5.5；Fastify 4.28；Knex 3.1（sqlite3 5.1 / mysql2 3.11）；uuid 9；**新增依赖 `@opencode-ai/sdk`**（web server 当前未引入，需加入）；tsx 4.16。
**前端**：React 18.3 / Zustand 4.5；Vite 5.3；TypeScript 5.5。原生 `EventSource` SSE；图谱用**内联 SVG**（不引重型图库，复刻 `openEuler-ops-qa.html` renderGraph）。
**MCP adapter**：Node/TS 轻量进程（stdio MCP server），桥接 LightRAG REST。
**外部**：LightRAG（REST `/query`，已部署或经 compose profile 可选起容器；不灌库）。

### 3.2 Core Decisions

#### Decision 1：单常驻 opencode server + 每会话一 session（DQ-001，偏离平台 D-001）
**Rationale**：QA 只读、无 SSH 凭据、无 hosts.ini、不起子代理，进程级强隔离收益极低；常驻多 session 原生多轮上下文、消除跨进程 storage 竞态、降资源。owner 隔离落 DB/路由层。
**Alternative**：每会话独立进程 + 用后即焚 HOME（拒绝：成本高、与只读场景不匹配、续跑竞态）。

#### Decision 2：LightRAG MCP adapter 全局声明 + agent allowlist + 后端解析 tool output（DQ-002）
**Rationale**：opencode MCP 只能全局声明（`mcp-config-handler.ts:59`），收敛靠 agent `permission` allowlist（`createAgentToolAllowlist`，先例 `multimodal-looker.ts:17`）；`state.output` 为 string（`cli/run/types.ts:95`），结构化检索数据经 JSON 字符串承载、后端解析+校验+降级。
**Alternative**：per-agent MCP 绑定（不存在）；依赖 SDK 直接给结构化对象（与代码事实冲突）。

#### Decision 3：可选模块 = config 门控 + 运行时能力探测（DQ-003）
**Rationale**：`config.conversation.enabled` 门控路由注册；`/api/capabilities` 供前端显隐；install/compose profile 控依赖与 LightRAG。运行时探测优于构建期开关（支持灰度/同镜像多环境）。
**Alternative**：构建期 `VITE_QA_ENABLED`（拒绝：不灵活，前后端易漂移）。

### 3.3 Data Model

**qa_sessions**（1:N → qa_messages）
- `id` UUID(PK)、`owner_id`(隔离键,idx)、`title`、`oc_session_id`(opencode sessionId,可空可重建)、`kb_id`(单库预留)、`created_at`/`updated_at` epoch ms。

**qa_messages**（N:1 → qa_sessions，`session_id` ON DELETE CASCADE）
- `id` UUID(PK)、`session_id`(FK,idx)、`role`('user'|'assistant')、`status`('generating'|'done'|'aborted'|'failed')、`text`(脱敏正文)、`retrieval`/`citations`/`graph`/`followups`(JSON 快照,可空)、`feedback`('useful'|'inaccurate'|null)、`created_at`。

### 3.4 Interface Contracts

REST + SSE（`/api/qa/*`，详见 [02 §6.1]）：
- `GET /api/capabilities` → `{ qa: boolean }`
- `POST /api/qa/sessions` / `GET /api/qa/sessions` / `GET|DELETE /api/qa/sessions/:id`
- `POST /api/qa/sessions/:id/messages` → `{ userMessageId, assistantMessageId }`（入队，single-flight；409 占用中）
- `POST /api/qa/sessions/:id/stop`
- `PUT /api/qa/sessions/:id/messages/:mid/feedback` → `{ feedback }`
- `GET /api/qa/sessions/:id/stream` → SSE：`qa_snapshot|qa_token|qa_trace_start|qa_trace|qa_evidence|qa_done|qa_error`
SSE 帧经 `desensitizeWith` 脱敏；越权统一 404。

### 4.2 Task Organization Strategy

**Organization Method**：Hybrid（按架构分层 + 功能耦合分组）。

**Rationale**：
- 后端持久化/调度/编排与前端渲染强耦合于「一次问答主链路」，Phase1 以**最薄端到端可运行链路**贯通（含可选门控），尽早暴露 opencode/MCP/LightRAG 集成风险（最高不确定性）。
- Phase2 在主链路之上补**多轮、历史、完整证据面板、交互动作、DFx 健壮性**（多为并行的增量）。
- Phase3 收**可选安装与交付**（install/compose/LightRAG profile/文档），依赖前两阶段稳定。

**MVP Scope**：
- **Phase 1 (MVP)**：单轮提问 → 经 QA agent + LightRAG MCP → 流式 token + 检索 trace + 证据（最小）端到端可见；模块可门控开关。
- **Phase 2 (Incremental)**：多轮上下文、会话历史/列表/回看、完整证据面板（图谱 SVG + [n]定位）、推荐/追问/复制/反馈/停止、脱敏、崩溃恢复、owner 隔离与降级测试。
- **Phase 3 (Delivery)**：install.sh 模块勾选、compose profile（含可选 LightRAG）、nginx/.env、交付文档与 DFx 收尾。

## §8 Appendix

### 8.1 Development Strategies

- **Delegate Tasks**：每个 T 任务委派 subagent 执行，主 Agent 仅汇总，控制上下文体量。
- **Multi-Agent**：Phase1 内 T103/T104/T105 可同时派发；Phase2 T202/T203/T204 可并行。
- **TDD**：T105（事件合成）、T102/T206（隔离/恢复）、降级分支均先写测试用例后实现。
- **集成风险前置**：最高不确定性（opencode 常驻 server + MCP + LightRAG 契约 TBD-004）集中在 Phase1，尽早联调校准。

### 8.2 Risk List

| Risk | Impact | Mitigation |
|------|------|----------|
| LightRAG `/query` 返回契约不符预期（TBD-004） | High | MCP adapter 规范化 schema + 容错降级；集成期校准；引用/图谱缺失优雅降级 |
| web 层首个真实 opencode 集成（无可复用 stub） | High | T103 直接对照 `cli/run/runner.ts` 真实范式；单测续跑；失败重连 |
| 全局 MCP 拖累其它 agent 初始化 | High | lazy 连接 + `disabled` 兜底；T104/T205 显式验证 xuanyuan 不受影响 |
| 常驻 server 单点崩溃 | Medium | 该轮 failed 可重试 + 重连/重建 session；崩溃面仅限 QA |
| `state.output` 解析失败 | Medium | safeJsonParse + schema 校验 + S-008 降级（不影响正文） |
| 并发/single-flight 竞态 | Medium | 锁释放时机明确（终态/abort 后）；409 仅占用时 |

### 8.3 Coding Notes

- **冻结区**：`src/opencode/*`（含 cli/run、agents、plugin-handlers）仅参照范式与复用 SDK/helper，**禁止修改**；复用 `auth/streamHub/desensitize/scheduler` 禁止改签名。
- **owner 隔离**：一律 repository 层越权返 null → 路由层 404（不泄露存在性）。
- **脱敏时机**：publish 与落库前，绝不在前端补脱敏。
