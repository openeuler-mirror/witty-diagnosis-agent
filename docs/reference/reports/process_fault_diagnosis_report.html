3.2 假设驱动排查

假设 A：空指针访问（nullptr）

检查项 操作 结论
崩溃地址 GDB 查看寄存器 RAX/RDI ❌ 地址为 0x7bb01a8b6000（非 NULL）
内存访问 GDB 尝试读取崩溃地址 ❌ "Cannot access memory"（地址已失效）

❌ 排除：崩溃地址非 NULL，非空指针访问问题。

假设 B：栈溢出（stack_overflow）

🧪 假设：递归调用过深或栈空间耗尽导致崩溃

检查项 操作 结论
栈深度 GDB bt full 查看调用栈 ✅ 仅 7 层，无递归
栈增长模式 检查调用栈符号重复 ✅ 无同一符号反复出现

❌ 排除：栈深度正常，无栈溢出迹象。

假设 C：堆损坏/malloc 错误（abort）

🧪 假设：内存分配器检测到堆损坏，触发 SIGABRT

检查项 操作 结论
崩溃信号 GDB info signals ❌ SIGSEGV (11)，非 SIGABRT (6)
调用栈符号 检查栈中是否有 malloc_printerr/abort ✅ 无堆检查相关符号

❌ 排除：信号非 SIGABRT，栈中无堆检查函数，非堆损坏。

假设 D：除零错误（divzero）

🧪 假设：浮点或整数除零导致 SIGFPE

检查项 操作 结论
崩溃信号 GDB info signals ❌ SIGSEGV，非 SIGFPE (8)
崩溃指令 GDB 反汇编查看崩溃位置指令 ✅ 为内存访问指令，非 div/idiv

❌ 排除：信号非 SIGFPE，崩溃指令为内存访问而非除法。

五、技术细节补充

5.1 Python 扩展模块崩溃特性

  • Python 解释器通过 C 扩展模块（libsensor_proc）执行业务逻辑
  • 崩溃发生在 C 层，而非 Python 解释器本身
  • GDB 的 py-bt / py-locals 无法定位 Python frame（提示 "Unable to locate python frame"）
  • 崩溃由 C 代码直接触发，Python 层无异常捕获机会

5.2 多线程环境

线程信息 内容
总线程数 11 个线程（Thread 1-11）
线程类型 所有线程均为 worker_thread，执行相同逻辑
崩溃线程 Thread 1 (LWP 17323)
其他线程状态 Thread 2-11 均处于 usleep 状态，未参与崩溃

5.3 内存映射特性

内存信息 内容
崩溃地址 0x7bb01a8b6000（mmap 区域）
映射大小 16384 字节（0x4000）
munmap 特性 内核立即回收页表映射，CPU 访问触发页故障
与堆/栈区别 mmap 区域在 munmap 后立即失效，不同于堆/栈延迟回收
