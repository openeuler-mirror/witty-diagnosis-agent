# 功能列表 (Features)

## 故障诊断能力

本项目基于**OS 全栈（硬件层→内核层→系统服务层）** 全维度故障模式梳理，系统构建故障诊断能力（通过表格 “Skill” 字段承载）。诊断能力将随故障场景丰富与技术方案迭代持续演进，具体故障模式及对应诊断能力如下表所示：

| 故障域                       | 故障模式                           | 故障描述                                                                                                                                     | 诊断方式 | Skill                                                                                          | 状态  |

| 磁盘                        | 磁盘预失效                          | 磁盘 SMART 监测到介质劣化、重映射扇区增长等异常，触发预失效预警，磁盘可靠性下降并持续上报潜在介质错误。                                                                                  | 在线   | [disk-health-diagnosis](skills/disk-health-diagnosis.md)                                       | 已支持 |
| 磁盘                        | UNC / UF 坏道故障                  | 磁盘读取特定扇区时，ECC 无法纠正数据错误（Uncorrectable Error），返回 MEDIUM ERROR。文件系统层收到 EIO，对应文件或分区无法访问，严重时触发内核 panic。                                       | 离线   | [offline-disk-fault-diagnosis](skills/offline-disk-fault-diagnosis.md)                         | 已支持 |

**诊断方式**：

- **在线**：智能诊断Agent将自动登录至故障服务器采集遥测数据并进行根因分析，需用户提供服务器的登录凭证。
