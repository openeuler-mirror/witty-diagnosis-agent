# 功能列表 (Features)

本文档用于后续补充功能细节与边界，建议按以下维度整理：

## 标准化诊断流程

`发现` → `收集` → `定位` → `根因` → `方案` → `实施` → `验证`

## 核心能力

- 信息收集与环境确认
- 分层定界与并行验证
- 风险控制与人工确认点
- 回归验证与结果落盘
