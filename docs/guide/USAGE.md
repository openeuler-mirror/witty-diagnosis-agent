# 使用指南 (User Guide)

本指南将帮助您快速上手 **Witty Diagnosis Agent**，了解其核心功能与交互模式。

## 快速开始 (Quick Start)

### 1. 启动 Agent
在安装完成后，您可以通过以下方式唤醒 Agent：

```bash
# 在终端中启动
witty-diagnosis-agent start

# 或者在 witty-diagnosis-agent 中直接 @witty-diagnosis-agent
```

### 2. 选择运行模式
Agent 启动后，您可以选择以下两种模式之一：

- **分阶段交互模式 (Interactive Mode)** [推荐]: 适合复杂故障，Agent 每一步都会与您确认。
- **全自动模式 (Autopilot Mode)**: 适合已知故障或快速排查，Agent 自动执行全流程。

## 核心功能详解

### 1. 故障诊断 (Diagnosis)
这是 Agent 的核心能力。您可以直接输入故障现象，例如：

> "服务器 SSH 连接不上，请帮我排查原因。"
> "MySQL 进程占用 CPU 过高，怎么回事？"

Agent 将按照以下流程工作：
1. **Fuxi (伏羲)**: 询问您更多细节（如 IP、时间点），生成诊断计划。
2. **Dayu (大禹)**: 拆解任务，调度执行者。
3. **Kuafu (夸父)**: 登录服务器执行 `top`, `netstat`, `grep` 等命令采集数据。
4. **Baize (白泽)**: 分析数据，生成根因报告。

### 2. 知识问答 (Q&A)
您可以询问运维相关的知识或 SOP：

> "Linux 系统如何查看内存占用？"
> "请给我一份 Nginx 性能优化的 Checklist。"

### 3. 自动化修复 (Remediation) [可选]
在查明根因后，您可以请求 **Nuwa (女娲)** 生成修复方案：

> "请生成一个脚本清理 `/var/log` 下的旧日志。"

## 进阶使用技巧

### 指定目标环境
在提问时，明确指定目标环境可以减少交互轮次：

> "请排查 **192.168.1.100** (用户: root) 上的 **8080 端口** 为何不通。"

### 查看中间结果
您随时可以要求查看当前的诊断计划或执行日志：

> "显示当前的诊断 Plan。"
> "查看刚才 `top` 命令的输出结果。"

### 干预执行
在分阶段模式下，您可以修正 Agent 的计划：

> "不要重启服务，先只收集日志。"
> "这个假设不对，请先排查网络问题。"

## 常见问题 (FAQ)

**Q: Agent 需要 root 权限吗？**
A: 视具体任务而定。读取系统日志通常需要 root 或 sudo 权限，普通用户可能受限。

**Q: 支持哪些操作系统？**
A: 目前深度适配 CentOS, Ubuntu, Debian, openEuler 等主流 Linux 发行版。

**Q: 诊断数据会上传云端吗？**
A: 默认情况下，所有数据采集和分析均在本地或您指定的内网环境中进行，不会上传至公网。
