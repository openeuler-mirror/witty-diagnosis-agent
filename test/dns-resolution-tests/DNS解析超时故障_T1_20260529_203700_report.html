4.1 应急处置

步骤 操作 执行人 预期效果
1 重启 WSL2 实例：在 Windows PowerShell 中执行 wsl --shutdown，然后重新打开 WSL 终端 系统 / 用户 重置 WSL2 网络堆栈，可能恢复 DNS 代理

3 临时禁用 Windows Defender 防火墙：在 PowerShell 中执行 Set-NetFirewallProfile -Profile Domain,Public,Private -Enabled False（验证后记得重新启用） 用户 验证是否为防火墙拦截问题
4 断开 VPN 连接：如有企业 VPN（如 Zscaler、Cisco AnyConnect、FortiClient 等），断开后测试 DNS 用户 排除 VPN 干扰（企业 VPN 经常与 WSL2 冲突）

4.2 永久修复计划

修复措施 负责人 完成时间 优先级
为 WSL2 配置固定 DNS：在 /etc/wsl.conf 中添加 [network] 节 generateResolvConf = false，然后手动创建 /etc/resolv.conf 指定外部 DNS（如 8.8.8.8 或内网 DNS 服务器） 用户 / 系统 故障恢复后 P1

4.3 修复命令参考

方案 A：配置固定 DNS 绕过 WSL DNS Proxy

bash 
# 1. 编辑 /etc/wsl.conf
sudo tee -a /etc/wsl.conf << EOF
[network]
generateResolvConf = false
EOF

# 2. 删除 WSL 管理的 resolv.conf
sudo rm /etc/resolv.conf

# 3. 创建固定 DNS 配置
cat << EOF | sudo tee /etc/resolv.conf
nameserver 8.8.8.8
nameserver 8.8.4.4
EOF

# 4. 重启 WSL2（在 Windows PowerShell 中）
# wsl --shutdown
# 然后重新打开 WSL
