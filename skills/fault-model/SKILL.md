# 故障模式关联映射规则 (Fault Mode Association Rules)

本 Skill 旨在辅助 Fuxi Agent 在识别出基础故障模式后，自动补齐其依赖或关联的底层组件模式。必须严格执行以下 **MANDATORY RULES（强制性规则）**。

## 1. 作用阶段 (Scope of Action)
*   **触发点**：在 Phase 1.4 的 **Step 1 (分类识别)** 识别出 ≥ 1 个故障模式后，立即调用。
*   **目标**：将单一或部分故障模式扩展为完整的专家推荐模式集。

## 2. 映射规则 (Association Rules)

根据输入的“起始模式 (Initial Mode)”，严格按以下表格进行映射。

| 起始模式 (Initial Mode) | 关联补齐输出 (Final Mode List) | 备注 |
| :--- | :--- | :--- |
| **文件系统故障** | `["文件系统故障", "磁盘故障"]` | 存储堆栈联动 |
| **磁盘故障** | `["文件系统故障", "磁盘故障"]` | 存储堆栈联动 |
| **其他模式** | `"无关联模型"` | **兜底逻辑 (Fallback)** |

### 强制执行细节：
1. **优先匹配**：若起始模式命中表格中具体的关联项（如文件系统或磁盘），必须 100% 遵守关联补齐结果。
2. **兜底输出**：一旦起始模式未命中上述任何具体的关联规则，**必须且仅能**输出字符串：`"无关联模型"`。
3. **严禁派生**：本 Skill 只负责“关联映射”，严禁自行补齐到 Top 3 或派生出子模式。

> [!IMPORTANT]
> **存储堆栈强制配对**：一旦涉及“文件系统故障”或“磁盘故障”，两者必须成对出现，确保诊断覆盖面。

---

## 3. 对流程的影响 (Impact on Fuxi Flow)
1. **短路逻辑 (Short-circuit)**：
   - 若输出为关联列表（如 `["文件系统故障", "磁盘故障"]`），则 Fuxi **立即进入 Step 3 (短路判断)** 并停止推断。
   - 若输出为 `"无关联模型"`，则 Fuxi 保持 Step 1 的识别结果，并根据 Step 3 规则决定是否继续执行后续推断。
2. **终止信号**：关联项的补齐被视为“专家确定性路径”，其优先级高于任何算法推断。
