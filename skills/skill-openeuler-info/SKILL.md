# openEuler系统信息速查技能

> 一键获取openEuler系统的关键信息

## 概述 (Overview)

本技能用于快速获取openEuler系统的基本信息，包括操作系统版本、内核版本、系统架构、硬件配置等关键信息。通过执行简单的命令，用户可以快速了解系统的基本情况，为后续的系统管理和故障排查提供基础信息。

## 何时使用此技能 (When to Use)

- **场景 1**：需要快速了解系统的基本配置信息
- **场景 2**：远程协助时需要提供系统信息
- **场景 3**：系统维护前的信息收集
- **场景 4**：技术支持时需要提供系统环境信息

## 核心概念

### 系统信息分类

- **系统基本信息**：操作系统版本、内核版本、系统架构
- **硬件信息**：CPU、内存、磁盘等硬件配置
- **网络信息**：IP地址、网络接口状态

## 使用方法 (Usage)

### 步骤 1：执行系统信息检查脚本

```bash
# 执行系统信息检查脚本
./scripts/check_system_info.sh
```

### 步骤 2：查看输出结果

脚本会自动收集并展示以下信息：

- 操作系统版本信息
- 内核版本信息
- 系统架构
- CPU信息
- 内存信息
- 磁盘使用情况
- 网络接口信息

## 可执行脚本工具

本技能包含一个辅助脚本，用于自动化检查系统信息。

### 脚本位置

- `scripts/check_system_info.sh`

### 脚本功能

收集和展示openEuler系统的基本信息，包括操作系统版本、内核版本、系统架构、硬件配置和网络信息。

### 使用说明

```bash
# 执行脚本
./scripts/check_system_info.sh

# 查看脚本帮助信息
./scripts/check_system_info.sh --help
```

### 脚本特点

- 只包含数据采集和分析相关的命令
- 单个命令失败不会中断整个脚本执行
- 所有命令都会尝试执行，失败时输出警告信息
- 输出格式清晰，便于阅读

## 注意事项

1. **权限要求**：执行脚本需要基本的系统读取权限
2. **适用范围**：仅适用于openEuler操作系统
3. **输出内容**：根据系统配置不同，输出内容可能会有所差异
4. **执行时间**：脚本执行时间通常在1-3秒内完成
