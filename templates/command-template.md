## 配置文件

<!--
描述命令的配置文件格式和位置
-->

### 配置文件位置
- 全局配置：`config/global.yaml`
- 命令特定配置：`config/commands/[命令名称].yaml`
- 用户配置：`~/.witty-diagnosis/config.yaml`

### 配置示例
```yaml
commands:
  [命令名称]:
    # 命令配置
    enabled: true
    default_options:
      target: "system"
      format: "json"
      timeout: 300

    # 技能配置
    skills:
      - "data-collector"
      - "log-analyzer"

    # 输出配置
    output:
      directory: "./reports"
      filename_template: "{command}-{timestamp}.{format}"

    # 性能配置
    performance:
      max_concurrent: 5
      cache_enabled: true
```

### 1. 初始化阶段
- 解析命令行参数和环境变量

- 检查系统依赖和权限
- 准备执行环境
- 初始化技能执行器
- 设置超时和资源限制

### 3. 执行阶段
- 执行前置钩子（hooks）
- 调用相关技能
- 处理技能执行结果
- 执行后置钩子（hooks）

### 4. 结果处理阶段

- 格式化输出

- 更新历史记录
- 发送通知（如果配置）
- 返回退出码
